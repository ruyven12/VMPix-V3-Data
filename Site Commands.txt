MUSIC-BANDS — POSTGRESQL DB ROUTE
==================================================

GET /api/music/bands/db
Reads Music-Bands directly from PostgreSQL table music_bands.

Current DB band JSON shape includes:
- band
- band_id
- general
- personnel
- stats

Supported query features:
- limit
- page
- search
- region filter
- status filter
- sorting
- sort direction

Metadata returned:
- ok
- route
- source
- generatedAt
- generatedTime
- count
- total
- page
- limit
- totalPages
- filters
- sort
- data

Safe limits:
- default limit: 50
- max limit: 100
- minimum page: 1

==================================================
MUSIC-BANDS — IMPORT / ADMIN ROUTE
==================================================

GET /admin/import/music/bands
Imports Google Sheet Music-Bands data into PostgreSQL.

Forced refresh:
https://vmpix-data.onrender.com/admin/import/music/bands?refresh=1

Current behavior:
- reads Google Sheets tab Music-Bands
- parses rows
- generates band_id if missing
- upserts into PostgreSQL table music_bands
- updates JSONB smart fields

IMPORTANT:
This route mutates/imports data. Use intentionally.


==================================================
MUSIC-SHOWS — PLANNED / NEXT ROUTES
==================================================

Sheet tab:
Music-Shows

PostgreSQL table:
music_shows

Primary ID:
show_id

ID behavior:
- show_id counts oldest to newest
- oldest show = 1
- newest show = highest number

Bands behavior:
- Sheet has band_1 through band_20
- Importer converts those columns into a readable bands array
- Empty band cells are ignored
- Slot order is preserved
- bandViewCount tracks historical appearance count up to that show

Target show object shape:

{
  "show_id": 1,
  "name": "Burning Time w/ Loki",
  "venue": "Colisee Club",
  "city": "Lewiston",
  "state": "Maine",
  "date": "3/14/26",
  "poster": "https://...",
  "notes": "",
  "camera_1": "Canon EOS R6 Mark II",
  "camera_2": "",
  "bands": [
    {
      "slot": 1,
      "band": "Loki",
      "bandViewCount": 13
    },
    {
      "slot": 2,
      "band": "Burning Time",
      "bandViewCount": 8
    }
  ],
  "stats": {
    "bandCount": 2
  }
}


==================================================
MUSIC-SHOWS — IMPORT / ADMIN ROUTE TO ADD
==================================================

GET /admin/import/music/shows?refresh=1
Imports Google Sheet Music-Shows data into PostgreSQL table music_shows.

Full URL:
https://vmpix-data.onrender.com/admin/import/music/shows?refresh=1

Expected behavior:
- reads Google Sheets tab Music-Shows
- processes rows chronologically oldest to newest
- assigns show_id in chronological order
- converts band_1 through band_20 into bands array
- calculates bandViewCount historically
- upserts into PostgreSQL table music_shows
- does not affect music_bands

IMPORTANT:
This route mutates/imports data. Use intentionally.

==================================================
IMPORTANT PROJECT RULES
==================================================

- This repo is VMPix-V3 Data only.
- Do not edit the live/original VMPix site from here.
- Backend only.
- No frontend edits.
- Surgical changes only.
- Do not break existing routes.
- Do not change /api/music/bands.
- Keep changes efficient because of rate/data caps.
- Read-only API routes must not mutate/import data.
- Import/admin routes should only run when explicitly called.
- Always run node --check server.js before saying done.
