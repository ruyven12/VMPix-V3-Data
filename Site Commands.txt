VMPix-V3 Data — Site Commands Reference

Base URL:
https://vmpix-data.onrender.com


==================================================
CORE HEALTH ROUTES
==================================================

/health
Basic backend health check.

/health/db
Tests PostgreSQL connection.

/health/tables
Lists PostgreSQL tables currently available.


==================================================
MUSIC-BANDS ROUTES
==================================================

Original Google Sheets / JSON Route

/api/music/bands

Current sheet-backed Music-Bands JSON route.
Preserved intentionally.


==================================================
POSTGRESQL MUSIC-BANDS ROUTES
==================================================

DB Read Route

/api/music/bands/db

Reads Music-Bands directly from PostgreSQL.

Supports:
?limit=10

Example:
/api/music/bands/db?limit=10


==================================================
MUSIC-BANDS STATS ROUTE
==================================================

/api/music/bands/stats

Returns grouped stats:
- bandTotals
- photoTotals
- percentages


==================================================
IMPORT / ADMIN ROUTES
==================================================

Music-Bands Import Route

/admin/import/music/bands

Imports Google Sheet Music-Bands data into PostgreSQL.

Supports forced refresh:
/admin/import/music/bands?refresh=1

Current behavior:
- reads Google Sheets
- parses rows
- generates band_id if missing
- upserts into PostgreSQL
- updates JSONB smart fields
